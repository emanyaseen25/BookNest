# BookNest 📚

BookNest is a front-end e-commerce website for buying books and novels online.

## Features

- Online bookstore homepage
- Search bar
- Book categories
- Featured books
- Best-selling novels
- Discount section
- Add to Cart buttons
- Responsive design
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
